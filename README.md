# Ahmed Ghazy's Portfolio

This is a static export of Ahmed Ghazy's portfolio website, built with Framer.

## Usage

To view the site locally:

1. Open `index.html` in your web browser.
2. Navigate through the portfolio sections.

## Structure

- `index.html`: Main portfolio page
- `work/`: Contains individual work project pages
  - `coretex/index.html`
  - `netfillx/index.html`
  - `walle/index.html`
- `404/index.html`: 404 error page
- `sitemap.xml`: Site map for SEO

## Troubleshooting

- If images or fonts don't load, ensure you're connected to the internet as some assets are hosted externally.
- For local development, you may need to serve the files via a local server to avoid CORS issues with external resources.

## Technologies

- Built with Framer
- Exported as static HTML/CSS/JavaScript
